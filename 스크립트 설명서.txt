## 🚀 스크립트 개요

**SV_Script (Universe V1)**는 Roblox 게임(특히 Grab 관련 게임)을 위한 종합 핵/유틸리티 스크립트입니다.

- **UI 라이브러리**: Obsidian (현대적이고 커스터마이즈 가능한 UI)
- **지원 게임**: Grab 시스템이 있는 Roblox 게임 (예: Universe 게임)
- **버전**: V1
- **제작자**: vadog (Belrock)
- **디스코드**: https://discord.gg/ZFe2Spryhx

## 🔐 보안 및 인증

### 화이트리스트 시스템
```lua
AllowedPlayers = {
    "WERTYUIO_PASDFGG", "WERTYUIO_PASDFG", 
    "Shiva_dog11", "bdturuj", "panda_0ais"
}
```
- **설명**: 지정된 사용자만 스크립트를 사용할 수 있습니다.
- **동작**: 화이트리스트에 없는 사용자는 자동으로 킥되며 Discord 초대 링크가 표시됩니다.

## 🏠 메인 기능 (메인 탭)

### 1. 이동 관련 기능

| 기능 | 설명 | 기본 키 |
|------|------|---------|
| **TP 워크** | 이동 방향으로 순간이동하며 걷기 | T |
| **점프력** | 점프 높이 조절 (1~1000) | J |
| **무한 점프** | 공중에서도 점프 가능 | K |
| **노클립** | 벽 통과 가능 | N |
| **플라이** | 자유 비행 모드 (속도 조절 가능) | F |
| **바다 걷기** | 바다 위를 걸을 수 있음 | O |
| **플립** | 앞/뒤로 공중제비 | Z(앞), X(뒤) |

### 2. 화면 관련 기능
- **강제 3인칭**: 항상 3인칭 시점 유지

### 3. 텔레포트 기능
- **즉시 TP (Q)**: 바라보는 방향으로 순간이동 (거리 조절 가능)
- **텔레포트 버튼**: 즉시 TP와 동일한 기능

- **페이크 코블록스**: 다리에 네온 효과 추가
- **안티 구찌 패스트**: 모든 블롭맨/트랙터 즉시 삭제
- **PCLD 브레이크**: 다른 플레이어의 파트 고정 해제
- **모든 안티 인풋 제거**: Input/AntiInput 이름의 파트 제거

## 🌀 텔레키네시스 (그랩 탭)

### 주요 기능
| 기능 | 설명 |
|------|------|

## ⚔️ 전투 기능 (전투 탭)

### 에임봇 & 레이지봇
| 기능 | 설명 |
|------|------|
| **에임봇** | 가장 가까운 적을 자동 조준 |
| **레이지봇** | 궤도 이동 + 자동 클릭 공격 |
| **백스탭** | 적 뒤로 순간이동 |

### 설정
- **궤도 반경**: 1~20
- **궤도 속도**: 5~100
- **탐색 범위**: 50~1000
- **클릭 딜레이**: 0.01~0.5초
- **백스탭 거리**: 0.5~5
